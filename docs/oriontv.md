# OrionTV 接入

客户端来自 [orion-lib/OrionTV](https://github.com/orion-lib/OrionTV)。本次实机使用 1.3.14，未在此仓库重新分发 APK 或修改客户端。下载和升级以其官方发行页为准。

1. 在 Android TV / 投影仪安装 OrionTV。
2. 在客户端服务端设置中，填写 `.local/service.json` 记录的 Cloud Run HTTPS 基础地址，通常不带额外路径。界面名称可能随版本变化。
3. 使用普通账号 `projector` 及自己在秘密初始化中设置的电视密码登录。管理员账号仅用于后台配置。
4. 搜索内容、打开详情并播放。收藏和进度由云端存储；视频连接由客户端直接发往媒体服务器。
5. 直播入口使用后台导入的 `lives` 配置；需要手动添加直播列表的客户端版本，可填写 `https://guovin.github.io/iptv-api/ipv4.m3u`、[来源示例](../cloud/sources.example.json) 中的 iptv-org 地址，或自己的 M3U 地址。

Guovin/iptv-api 是收集、整理和生成直播节目列表的项目；本方案使用它发布的公共 M3U 结果，没有在 Cloud Run 运行全量采集器。iptv-org 示例包括台湾、中文、香港、新加坡、马来西亚五个列表。台湾列表以台湾本地频道为主；中文列表补充港澳、新马华语台和大陆城市台；香港、新加坡、马来西亚列表另含当地粤语、英语等频道。这些列表与 Guovin 的央视、卫视只有少量重复，但彼此之间有重叠，例如台湾与中文列表有 26 个频道重复，香港列表 17 个地址中 10 个也在中文列表里，同一频道可能出现在多个列表中。iptv-org 列表不带可用的节目单，部分只指向美国节目单压缩包，LunaTV 不解压，这些频道可能没有节目信息。部分频道限所在地区播放，能否播放取决于电视所在网络。点播 API 另行配置，与直播不是同一个源。

## 排查

- 登录或搜索首次较慢：Cloud Run 最小实例为 0，可能发生冷启动。
- 搜索能用、视频不通：检查投影仪到媒体服务器的网络和来源可用性；后端刻意禁用媒体代理，Cloud Run 能访问不代表电视能访问。
- 整个后端不可用：先看费用保护是否把服务设为手动 0 实例，或是否已经到期关闭项目计费。
- 更新来源后客户端仍显示旧内容：重新加载客户端列表；本配方禁用后台 cron，来源自动巡检不在运行。
- 单源查找会忽略标题空格差异；如果源站把空格作为宽泛搜索条件导致未命中，会额外尝试一次去空格标题。仍要求完整标题一致，不会把不同季、电影版或解说当作同一部作品。普通搜索可输入剧名，再选择具体季。
- 《绝命毒师》可优先尝试如意、无尽、iKun。2026-10-24 的抽查在这三个源各取五季第一集，播放清单及一个中段分片均可读取；不代表全剧每集、电视端播放或长期稳定性保证。现用量子源的第一季第一集当次返回 404，保留该源供其他内容使用。

验证媒体直连时，客户端播放地址应指向源站，不应是本后端 `/api/proxy/segment`、`m3u8`、`key`。后端对这些接口返回 403；匿名搜索返回 401。
